# Customer_Churn_Analysis
Customer Churn Analysis using SQL and Power BI to identify churn patterns, analyze customer behavior, and uncover key factors influencing customer retention through interactive dashboards and data-driven insights.

## Project Overview
This project analyzes customer churn data using SQL and Power BI to identify churn patterns, customer behavior, and the key factors influencing customer retention. The goal is to provide actionable business insights that can help reduce customer churn and improve retention strategies.

## Objectives
- Calculate the overall customer churn rate.
- Identify factors contributing to customer churn.
- Analyze churn based on contract type, tenure, techsupport, and internet service.
- Compare churn across different customer segments.
- Build an interactive Power BI dashboard for business insights.

## Tools & Technologies
- SQL Server (SSMS)
- Power BI
- SQL
- DAX

## Key KPIs
- Total Customers
- Churned Customers
- Churn Rate (%)
- Average Monthly Charges
- Average Tenure

## Dashboard Features
- count of churn by gender
- count of churn by age
- sum of monthly charges by age
- max of total charges by churn
- count of tech support and count of churn by gender
- sum of total charges by contract type
- count of internet service by churn
